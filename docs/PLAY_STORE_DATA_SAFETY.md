# Play Store Data Safety

## Data Collection and Sharing

### Does your app collect or share any of the required user data types?
**Yes.**

### Is all of the user data collected by your app encrypted in transit?
**Yes** — TLS for all network requests.

### Do you provide a way for users to request that their data is deleted?
**Yes** — In-app: Settings → Delete All Data or via email: support@periodsaathi.app

---

## Data Collected

### App activity
- Collected: Yes (if analytics opted in)
- Shared: No
- Required for app to function: No
- User can request deletion: Yes

### App info and performance (crash logs)
- Collected: Yes (if crash reporting opted in)
- Shared: Yes — with Firebase Crashlytics
- Required for app to function: No
- User can request deletion: Yes

---

## Data NOT Collected

### Health and fitness data
**NOT collected by us** — Period dates, symptoms, flow data stored ONLY on device.

### Personal communications (journal entries)
**NOT collected by us** — Journal entries encrypted on device, never synced.

### Location
**NOT collected** — We never request location permission.

### Photos and videos
**NOT collected** — We never access camera or photo library.
